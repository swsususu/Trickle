## Trickle 0.0.8

### 修复 / Fixed

- **面板关着也在反复唤醒 WebKit**：每次采样，后端都会把功率和系统负载数据推给主窗口
  和菜单栏面板两个页面，不管它们是否显示。面板几乎一直关着，WebKit 每次都要先唤醒
  已挂起的页面进程执行脚本，再重新挂起，每次采样产生约 70 行系统日志
  （`markLayersVolatile`、`ProcessThrottler` 等）。现在数据只推给屏幕上可见的页面，
  隐藏期间的采样先缓存起来（最多 60 条），面板打开或主窗口获得焦点时一次性补发，
  曲线不会断。实测 5 秒刷新间隔、窗口全部隐藏时，45 秒内的相关日志从 664 行降到
  4 行，页面进程 CPU 为 0%。

  **WebKit woken on every tick while the panel is closed**: every sample was
  pushed to both the main window and the status bar panel, shown or not. The
  panel is closed nearly all the time, so WebKit resumed its suspended page
  process on every tick just to run the script, then suspended it again,
  logging about 70 lines each time (`markLayersVolatile`, `ProcessThrottler`
  and so on). Samples now go only to a page that is on screen. Those taken
  while it is not are queued (up to 60) and delivered in one batch when the
  panel opens or the main window gains focus, so the charts stay continuous.
  At a 5 s interval with every window hidden, the related logging over 45 s
  went from 664 lines to 4, and the page process sits at 0% CPU.

- 主窗口负载图中的功率值现在与同一次采样对齐，此前用的是上一次的读数。

  The power line in the main window's load chart now comes from the same
  sample, not the previous one.

### 安装 / Install

已安装的用户会收到应用内更新提示，或执行 `brew upgrade --cask swsususu/tap/trickle`。
Existing installs will be offered the update in-app, or run
`brew upgrade --cask swsususu/tap/trickle`.

新安装请下载下方 `.dmg`。应用未公证，首次打开请右键选择「打开」，或执行：
For a new install, download the `.dmg` below. It is not notarised, so
right-click → Open the first time, or run:

```
xattr -dr com.apple.quarantine /Applications/Trickle.app
```
