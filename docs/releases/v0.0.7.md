## Trickle 0.0.7

### 修复 / Fixed

- **运行越久内存越高（#4）**：WebKit 会冻结隐藏页面的动画时间线，而菜单栏面板在
  WebKit 看来始终是隐藏的。功率条和负载条每次刷新都会启动新的 CSS 过渡动画，这些
  动画永远不会结束，被替换掉的旧动画占用的内存也不会释放，于是 `tauri://localhost`
  进程每 1000 次刷新约增长 120 MB，长时间运行可达数 GB。现在页面隐藏时会关闭过渡
  动画。实测 500 ms 刷新间隔下运行 8 分钟，面板进程的 WebKit 内存修复前从 21 MB
  涨到 85 MB，修复后为 17 MB 到 20 MB。

  **Memory climbing the longer the app runs (#4)**: WebKit freezes a hidden
  page's animation timeline, and the status bar panel is always hidden as far as
  WebKit is concerned. The power bar and load meters started a new CSS
  transition on every tick; none of them ever finished and the replaced ones
  were never freed, so the `tauri://localhost` process grew by about 120 MB per
  1000 ticks and could reach several GB. Transitions are now off while the page
  is hidden. At a 500 ms interval over 8 minutes, the panel's WebKit memory went
  from 21 MB to 85 MB before the fix, and from 17 MB to 20 MB after.

  代价：面板中的功率条和负载条不再有过渡动画，数值变化时直接跳到新位置。主窗口
  在可见时不受影响。

  Trade-off: the bars in the panel now jump to new values instead of sliding.
  The main window still animates while visible.

### 安装 / Install

已安装的用户会收到应用内更新提示，或执行 `brew upgrade --cask swsususu/tap/trickle`。
Existing installs will be offered the update in-app, or run
`brew upgrade --cask swsususu/tap/trickle`.

新安装请下载下方 `.dmg`。应用未公证，首次打开请右键选择「打开」，或执行：
For a new install, download the `.dmg` below. It is not notarised, so
right-click → Open the first time, or run:

```
xattr -dr com.apple.quarantine /Applications/Trickle.app
```
