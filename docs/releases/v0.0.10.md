## Trickle 0.0.10

### 修复 / Fixed

- **MacBook Air 屏幕功耗显示一个固定的 `~1.2w`**（#5）：0.0.9 根据 `AppleARMBacklight`
  的背光驱动电流估算屏幕功耗，但这组数据是静态快照，在 M2 Air 上从最亮调到最暗都不变，
  算出来的是一个没有意义的常数。现在去掉了这个估算。

  同时新增读取 `PBLR`，这是基础款 M2/M3/M4 芯片的屏幕功率键，此前没有读，所以基础款
  MacBook Pro 现在也能显示实测的屏幕功耗。MacBook Air 上虽然有 `PBLR`，但亮度怎么调都是 0，
  因此只有某个屏幕键读到过 0.1 W 以上才认为有屏幕传感器。没有的 Mac 上，功率流显示 `N/A`，
  功耗条和曲线不再画屏幕部分，菜单栏选了「屏幕功率」时也显示 `N/A`。

  **Screen power on MacBook Air showed a fixed `~1.2w`** (#5): 0.0.9 estimated
  screen power from the backlight drive current in `AppleARMBacklight`, but
  that turned out to be a static snapshot. On an M2 Air it did not change from
  full brightness to fully dimmed, so the estimate was a meaningless constant.
  It is gone.

  Trickle now also reads `PBLR`, the screen power key on base M2/M3/M4 chips,
  so base MacBook Pros show measured screen power too. MacBook Airs list
  `PBLR` but it reads 0 at any brightness, so a screen sensor only counts once
  it has read at least 0.1 W. On Macs without one, the power flow shows `N/A`,
  the power bar and chart leave the screen out, and the menu bar shows `N/A`
  when set to screen power.

### 安装 / Install

已安装的用户会收到应用内更新提示，或执行 `brew upgrade --cask swsususu/tap/trickle`。
Existing installs will be offered the update in-app, or run
`brew upgrade --cask swsususu/tap/trickle`.

新安装请下载下方 `.dmg`。应用未公证，首次打开请右键选择「打开」，或执行：
For a new install, download the `.dmg` below. It is not notarised, so
right-click → Open the first time, or run:

```
xattr -dr com.apple.quarantine /Applications/Trickle.app
```
