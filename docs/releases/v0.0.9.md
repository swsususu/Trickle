## Trickle 0.0.9

### 修复 / Fixed

- **MacBook Air 等机型屏幕功耗一直是 0.0 W**（#5）：屏幕功耗原本只读 SMC 的 `PDBR`，
  而这个键只有 MacBook Pro 的 mini-LED（XDR）屏才有，M5 / A18 机型改用 `PBwo`，
  其余机型两者都没有。现在依次读取 `PBwo`、`PDBR`；都没有时根据 `AppleARMBacklight`
  公布的背光驱动电流估算，合盖时为 0。估算值在功率流中以 `~` 标出。macOS 不提供
  LED 电压，估算值只是近似，但会随亮度变化。

  **Screen power stuck at 0.0 W on MacBook Air and others** (#5): screen power
  came only from the SMC key `PDBR`, which only mini-LED (XDR) MacBook Pros
  have. M5 / A18 machines use `PBwo` instead, and other Macs have neither.
  Trickle now reads `PBwo`, then `PDBR`, and otherwise estimates the power from
  the backlight drive current published by `AppleARMBacklight` (0 with the lid
  closed). Estimated values are marked with `~` in the power flow. macOS does
  not expose the LED voltage, so this is an approximation, but it tracks
  brightness.

- **菜单栏数字左侧大片空白**（#6）：菜单栏项的宽度只增不减，文字又右对齐，
  出现过一次较宽的读数（如充电时的 `67.0w`）后，之后的 `5.5w` 左侧就一直留空。
  现在读数变宽时立即加宽，连续 5 次变窄后再收缩，读数在 `9.9`/`10.0` 之间跳动时
  也不会来回抖动。

  **Empty space to the left of the menu bar reading** (#6): the item's width
  only ever grew and the text is right-aligned, so after one wide reading (such
  as `67.0w` while charging) a later `5.5w` kept a gap on its left. The width
  now grows at once and shrinks back after 5 narrower updates, so it still does
  not jitter around `9.9`/`10.0`.

### 安装 / Install

已安装的用户会收到应用内更新提示，或执行 `brew upgrade --cask swsususu/tap/trickle`。
Existing installs will be offered the update in-app, or run
`brew upgrade --cask swsususu/tap/trickle`.

新安装请下载下方 `.dmg`。应用未公证，首次打开请右键选择「打开」，或执行：
For a new install, download the `.dmg` below. It is not notarised, so
right-click → Open the first time, or run:

```
xattr -dr com.apple.quarantine /Applications/Trickle.app
```
