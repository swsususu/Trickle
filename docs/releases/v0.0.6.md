## Trickle 0.0.6

### 修复 / Fixed

- **运行越久 CPU 越高（#2）**：菜单栏面板关闭时，WebKit 会冻结它的动画时间线，
  但功率数字的滚动动画每次刷新仍会新建，且永远不会结束，于是不断堆积，每次样式
  计算都要遍历它们。实测 500 ms 刷新间隔下，面板进程 CPU 9 分钟内从 2.5% 涨到 8.6%，
  并会一直上涨。现在只在面板可见时播放数字动画，同样条件下全程稳定在 1.3–1.7%。

  **CPU climbing the longer the app runs (#2)**: while the status bar panel is
  closed, WebKit freezes its animation timeline, but the power readout still
  started a new digit animation on every tick, and none of them ever finished.
  They piled up and every style recalculation walked all of them. At a 500 ms
  interval the panel's process went from 2.5% to 8.6% CPU in 9 minutes and kept
  rising. The readout now only animates while visible; under the same conditions
  it stays at 1.3–1.7%.

  如果你在 0.0.5 或更早版本上遇到这个问题，此前的临时方案是在 **设置** 中关闭
  「动画」，升级后可以重新打开。

  If you turned off **Settings → Animations** as a workaround, it is safe to turn
  it back on.

### 安装 / Install

已安装的用户会收到应用内更新提示，或执行 `brew upgrade --cask swsususu/tap/trickle`。
Existing installs will be offered the update in-app, or run
`brew upgrade --cask swsususu/tap/trickle`.

新安装请下载下方 `.dmg`。应用未公证，首次打开请右键选择「打开」，或执行：
For a new install, download the `.dmg` below. It is not notarised, so
right-click → Open the first time, or run:

```
xattr -dr com.apple.quarantine /Applications/Trickle.app
```
