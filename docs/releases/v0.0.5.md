## Trickle 0.0.5 — 系统负载 / System load

> 这是 `feat/system-monitor` 分支的第一个版本。只想要功率监控的用户：可以在
> **设置 → 系统负载** 中关闭「监控系统负载」，关闭后完全不采集，行为与之前一致。
>
> First release from the `feat/system-monitor` branch. If you only want power
> monitoring, turn off **Settings → System Load → Monitor System Load**; nothing is
> sampled and the app behaves as before.

![主窗口 / Main window](https://raw.githubusercontent.com/swsususu/Trickle/v0.0.5/docs/images/screenshot.png)

### 新增 / New

**系统负载 / System load**

![系统负载 / System load](https://raw.githubusercontent.com/swsususu/Trickle/v0.0.5/docs/images/system-load.png)

- **CPU**：总占用 + 每核柱状图，区分能效核 / 性能核
  Overall and per-core usage, efficiency and performance cores split
- **GPU**：占用率与显存占用；GPU 不报告占用率时自动隐藏
  Utilisation and driver memory; hidden when the GPU reports none
- **内存 / Memory**：以内存压力为主，拆分 App / 联动 / 压缩与交换
  Pressure first, with app / wired / compressed breakdown and swap
- **网络 / Network**：上下行速率与开机累计；只统计物理接口，VPN 不重复计数
  Up/down rate and totals since boot; physical interfaces only, so VPN traffic is not counted twice
- **负载 × 功耗 / Load × Power**：功率与负载叠在同一时间轴，回答「这 20W 花在哪」
  Power and load on one time axis, to show what the watts are spent on
- **应用耗电排行 / Energy by app**：新增 CPU 与内存列
  Now with CPU and memory columns

**菜单栏 / Menu bar**

<img src="https://raw.githubusercontent.com/swsususu/Trickle/v0.0.5/docs/images/popover.png" width="378" alt="菜单栏面板 / Menu bar panel"> <img src="https://raw.githubusercontent.com/swsususu/Trickle/v0.0.5/docs/images/statusbar.png" width="284" alt="状态栏样式 / Status bar styles">

- 面板底部新增一行迷你指标，面板高度随内容自适应
  A compact row of load figures in the panel, which resizes to fit
- 状态栏可在功率后附加双行小字：`+ CPU`、`+ 网速`、`+ CPU/GPU/内存`（设置 → 状态栏附加信息）
  Optional two-line stacks after the power figure (Settings → Status Bar Extra)
- 状态栏改为原生绘制：数字等宽、宽度不再随读数跳动，深浅色菜单栏自动适配
  The status item is now drawn natively: tabular digits, stable width, tinted by macOS

### 其他 / Other

- 声明最低系统版本为 macOS 11（此前为 Tauri 默认的 10.13）
  Declares macOS 11 as the minimum (was Tauri's 10.13 default)
- 所有系统数据来自内核计数器，无需 root，也不新增定时器；仅菜单栏状态下开启负载监控 CPU 约增加 0.05 个百分点
  All figures come from kernel counters, no root, no extra timer; about +0.05 pp CPU in menu-bar-only use

### 已知限制 / Known limitations

- 在 macOS 27 / Apple Silicon 上验证；macOS 26 与 Intel 未经实机测试
  Verified on macOS 27 / Apple Silicon; macOS 26 and Intel not tested on hardware
- Intel Mac 没有能效核 / 性能核之分
  No efficiency/performance split on Intel

### 安装 / Install

下载下方的 `.dmg`，拖到「应用程序」。应用未公证，首次打开请右键选择「打开」，或执行：
Download the `.dmg` below and drag Trickle to Applications. It is not notarised, so right-click → Open the first time, or run:

```
xattr -dr com.apple.quarantine /Applications/Trickle.app
```

已安装旧版本的用户会收到应用内更新提示。
Existing installs will be offered the update in-app.
